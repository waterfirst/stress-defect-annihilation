Supplementary code and processed numerical data
================================================

This archive supports only the dimensionless reduced-order calculation reported in
the manuscript. It contains the deterministic model implementation, unit tests,
figure/data builder, parameter manifest, and CSV files behind the numerical plots.

Run the tests from the repository research directory with:
  python -m unittest -v test_reduced_order_model.py

The archive does not contain raw Mueller matrices, absolute laser settings, or
specimen-level production records. The experimental panels in the manuscript are
unaltered raster exports from the authors' retained project files.
